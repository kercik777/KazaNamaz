# Пропущенные Намазы (Каза-намаз трекер)

Красивое приложение для учёта пропущенных намазов на Android. Полностью на русском языке.

## Возможности

- **Отметка каждого намаза отдельно**: у каждого из шести намазов (Фаджр, Зухр, Аср, Магриб, Иша, Витр) — две явные кнопки **«Выполнен»** и **«Пропущен»**. По умолчанию день нейтральный (ничего не отмечено). Повторное нажатие на активную кнопку снимает отметку (возврат в «не отмечено»).
- **Календарь**: пропущенные дни автоматически помечаются красным кружком с числом пропусков; полностью выполненные дни — зелёной точкой; сегодня — золотой рамкой. Нажмите на любой день, чтобы посмотреть и изменить его.
- **Статистика**: общее число пропусков и выполненных, дни в истории, текущая и рекордная серия без пропусков, разбивка по каждому намазу и по месяцам.
- **Заметки** на каждый день.
- **Резервное копирование**: экспорт в JSON-файл (системный выбор папки), импорт с предупреждением о замене данных, а также «Поделиться копией».
- **Тёмная / светлая / системная тема**.
- **Быстрые действия**: «Всё выполнено», «Всё пропущено», «Сбросить день».
- Никакой рекламы. Все данные хранятся только на устройстве.

## Технические детали

- **Язык**: чистая Java (без Kotlin).
- **Без ViewBinding** — только `findViewById`.
- **Только официальные библиотеки Google** (AndroidX + Material Components). Никаких сторонних библиотек (нет Retrofit, Glide, EventBus и т.п.).
- **Системный шрифт** — никаких `.ttf`.
- **Ноль чувствительных разрешений**: в манифесте нет ни одного `uses-permission`. Экспорт/импорт работает через системный выбор файлов (Storage Access Framework), поэтому Google Play не задаст вопросов.
- **minSdk 26** (Android 8.0+), **targetSdk 35**.
- Адаптивная векторная иконка (мечеть) + монохромная версия для Android 13+.

## Как открыть и собрать

1. Откройте Android Studio.
2. **File → Open** → выберите папку `KazaNamaz`.
3. Дождитесь синхронизации Gradle (Gradle 8.9, AGP 8.7.3, JDK 17).
4. Запустите на устройстве/эмуляторе (Run ▶).

В папке проекта уже есть `gradlew` и `gradle/wrapper`, поэтому сборка скачает всё нужное автоматически.

### Сборка APK вручную

```bash
./gradlew assembleDebug        # отладочный APK (можно сразу ставить)
./gradlew assembleRelease      # релизный APK (R8 + оптимизация)
```

## Публикация в Google Play

1. **Build → Generate Signed Bundle / APK…** → создайте keystore (или используйте Play App Signing).
2. Соберите `release` вариант и загрузите `.aab` в Play Console.
3. Иконка для магазина (512×512) лежит рядом с проектом: `play-store-icon-512.png`.
4. В консоли разработчика в разделе «Безопасность данных» укажите, что приложение **не собирает и не передаёт** никаких данных.

## Формат резервной копии

JSON-файл вида:

```json
{
  "app": "KazaNamaz",
  "formatVersion": 1,
  "records": [
    { "date": "2026-08-22", "flags": "010200", "note": "опоздал на работу" }
  ]
}
```

Каждый символ `flags` — один намаз в порядке Фаджр, Зухр, Аср, Магриб, Иша, Витр:
`0` — не отмечено, `1` — пропущен, `2` — выполнен.
